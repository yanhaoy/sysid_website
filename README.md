# Coordinate-Independent Robot Model Identification

Project page for Yanhao Yang and Ross L. Hatton's IROS 2026 paper, [Coordinate-Independent Robot Model Identification](https://arxiv.org/abs/2603.14656).

The site is a static page built with the [Academic Project Page Template](https://github.com/eliahuhorwitz/Academic-project-page-template). Edit `index.html` for page content, `static/css/index.css` for styling, and `static/js/index.js` for the BibTeX copy button. The poster is at `static/pdfs/poster.pdf`.

To preview locally, run `python3 -m http.server 8000` from the repository root and open `http://localhost:8000`.
